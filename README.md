# سوار الكف الذكي - مشروع رعاية وزيارة أولي الألباب
نظام برميجي متكامل يربط بين سوار إلكتروني وتطبيق هواتف ذكية بلغة فلاتر لخدمة الزائرين.

## مميزات النظام:
1. اتصال صوتي وتحديد مواقع بين أفراد العائلة بدون إنترنت وبدون رصيد أموال (Mesh Network).
2. فحص مستمر للنبض والحركة وإرسال استغاثة آلية لمستشفيات العتبة الحسينية عند الإغماء.
3. مساعد عقائدي وتنبيه فقهي ذكي بالذكاء الاصطناعي يعتمد على موقع الزائر الجغرافي.
4. شحن ذاتي للبطارية من طاقة خطوات المشاية وتوصيل الصوت عبر اهتزاز عظام الفك.
